# MahjongGame

在 Minecraft 里和朋友联机打麻将的 NeoForge 模组，由 bingbohejun（作者）开发维护。
支持**日本立直麻将（四人 / 三人）**与**四川麻将（血战到底）**三种玩法，内置电脑机器人，
完整实现了宝牌、役种、符番计算、流局判定等日麻规则，四川麻将则有独立的番型计分。
---

## 支持的玩法

| 玩法         | 说明                                                                     |
| ---------- | ---------------------------------------------------------------------- |
| 日本麻将（四人）   | 标准立直麻将，含宝牌 / 赤宝牌 / 里宝牌、立直 / 双立直、各种役与役满、流局判定（九种九牌 / 四家立直 / 四风连打 / 四开杠）等 |
| 日本麻将（三人）   | 三人立直麻将，摸到北可「拔北」（每张北算 1 番，结算以宝牌形式显示）                                    |
| 四川麻将（血战到底） | 缺一门 · 自摸限定 · 血战到底；刮风下雨（杠分）、退税、地胡 / 天胡、十八罗汉均支持，使用独立的番型计分器（见下）           |

### 四川麻将计分

四川麻将不走日麻的役 / 符，改用独立番型：平胡 1 / 对对胡 2 / 七对 3 / 龙七对 3 / 清一色 3 / 带幺九 3 /
金钩钓 3 / 根每根 +1 / 自摸 +1 / 杠上花 +1 / 海底捞月 +1 / 天胡 6 / 地胡 6 / 十八罗汉 6。
分数 = `500 × 2^(番 - 1)`，**5 番封顶（每家 8000 分）**。

## 环境要求与依赖

必须同时安装以下 4 个模组（全部放进 `mods/`）：

| 文件                                            | 说明                                                                |
| --------------------------------------------- | ----------------------------------------------------------------- |
| `MahjongGame-mc1.21.1-<版本>+1.21.1.jar`        | 本体（已内嵌 [mahjong4j](https://github.com/mahjong4j/mahjong4j) 0.3.2） |
| `ciallolib-mc1.21.1-1.0.0+1.21.1.jar`         | **GUI 函式库**（本模组的必需依赖）                                         |
| `kotlinforforge-neoforge-5.12.0.jar`          | Kotlin 运行时（必需前置）                                                  |
| `cloth-config-neoforge-15.0.140-neoforge.jar` | 配置界面（必需前置）                                                       |

客户端与服务端都要装这 4 个。需要 **Minecraft 1.21.1 + NeoForge 21.1.127+**。

## 怎么玩

1. **创造模式**在 `MahjongGame` 标签页里取出「麻将桌」「麻将凳」等。
2. 放下**麻将桌** → 右键打开等待界面（由 CialloLib 绘制）。
3. 在等待界面**加入机器人 / 准备**；主持人点击「开始」开局。
4. 机器人会坐到麻将凳上、面朝牌桌；桌面中央面板显示对局信息，左侧为快捷操作 HUD。
5. 轮到行动时，屏幕中央弹出吃 / 碰 / 杠 / 立直 / 荣和 / 自摸 / 拔北 / 跳过等按钮，鼠标点击选择。
6. 想结束对局：准心对准桌面中央的「结束」按钮，按使用键发起结束投票。

### 按键

| 按键                           | 功能                                                         |
| ---------------------------- | ---------------------------------------------------------- |
| `;`（分号）                      | 打开配置界面                                                     |
| 开启 HUD 位置编辑器                 | 调整 HUD 在屏幕上的位置（需在设置 → 按键里绑定）                               |
| 开启役种画面                       | 打开役种总览（需在设置 → 按键里绑定）                                       |
| 切换 自动理牌 / 自动和牌 / 不吃碰杠 / 自动摸切 | 对局中直接切换左侧快捷操作 HUD 的四个开关（需在设置 → 按键里绑定，默认未绑定；切换后聊天栏会提示开 / 关） |

配置界面也可从 **Mods 菜单 → MahjongGame → Config** 进入。

## 构建（开发用）

```bash
# 先构建 CialloLib，把它的 dev jar 放进本工程的 libs/ 供编译使用
cd ../CialloLib && ./gradlew build
cp ../CialloLib/build/devlibs/ciallolib-mc1.21.1-*-dev.jar libs/

# 构建本体，产物：build/libs/MahjongGame-mc1.21.1-<版本>+1.21.1.jar
./gradlew build
./gradlew runClient   # 开发环境启动客户端（需把 CialloLib 的 dev jar 放进 run/mods/）
./gradlew runServer   # 开发环境启动专用服务器
